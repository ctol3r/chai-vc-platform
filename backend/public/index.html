VitalCV API Documentation

Welcome to the developer documentation for the VitalCV API. Below is a list of available endpoints and examples of how to use them.

You can also view the full OpenAPI specification here.

Method Endpoint Description cURL Example
GET /verifier/credential/{credentialId}/status Retrieves the status of a specific credential by its ID. curl http://localhost:4000/verifier/credential/123/status
POST /credentials Creates a new credential. (Placeholder implementation) curl -X POST http://localhost:4000/credentials -H "Content-Type: application/json" -d '{"name": "Medical License", "issuer": "did:example:123"}'
